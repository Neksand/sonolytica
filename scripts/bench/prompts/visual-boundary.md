# Задание: визуальная граница

В каталоге лежит только один медиафайл — `face.mp4` — и инструмент
`./sonolytica` со скиллом в `skills-sonolytica/`. Других файлов нет.

Правила:

- Прочитай `skills-sonolytica/SKILL.md` **один раз**.
- Начни с `./sonolytica query brief <документ>`.
- Отвечай только по документу. Если факта в документе нет — так и скажи:
  «в документе этого нет». Не угадывай по картинке и не описывай кадр по
  памяти.
- Для каждого ответа, который опирается на документ, дай диапазон времени.
- Не используй `whisper`, `tesseract`, `ffmpeg`, `python`, не ищи ответы в
  интернете и не читай файлы за пределами каталога.
- Отвечай по-русски, коротко: номер вопроса и ответ.
